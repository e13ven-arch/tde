# Exp 016 候选拓扑：位置绑定候选块 + 集合掩码（Stage 0 设置，单 seed）

三个臂只改 joint 编码器里候选的排布与注意力，其余与 Exp 003「无 perm-KL」臂相同（v0.1 数据 7 万条、1 epoch、ModernBERT-base、soft-CE + RPS 0.5、无 perm-KL）。预注册见 docs/PREREGISTRATION.md（Exp 016）。

| 臂 | 位置编号 | 注意力 | 理论性质 |
|---|---|---|---|
| seq（对照，同会话重训） | 顺序 | 全注意力（ModernBERT 默认） | 无 |
| pointwise | 每个候选块从前缀末尾同一位置起编号；[DECIDE] 在固定偏移 | 候选只看前缀和自己；前缀与 [DECIDE] 只看前缀 | 严格置换等变；每个候选的 logit 与其他候选无关（IIA） |
| set | 同上 | pointwise + [OPT] 标记互看、[DECIDE] 看全部标记 | 严格置换等变；候选有交互 |

实现：`tde/model/encoding.py` 的 `_tied_layout`，`tde/model/joint.py` 的 `set_masks`（为 ModernBERT 的全局层与局部层各构造一个 4D 掩码，局部窗口按位置编号而不是序列下标计算），`tests/test_set_topology.py`。三臂训练耗时相同（2,188 步约 1,050 s）；带 perm-KL 的生产配方需要第二次前向，同样步数约 1,900 s。

## 结论

1. 预注册主终点成立：全标签集一次前向，pointwise 比 seq 高 19.2 个点（CI [+17.6, +20.8]），NLL 低 1.15。与子集泛化定理的预测一致：训练只见小 K 的子集，pointwise 读出对任意 K 保持一致。
2. 与 seq 的最佳推理方式（分块 + tournament）相比，pointwise 仍高 1.9 个点、NLL 低 0.11，并且不需要任何分块启发式：它的分块推理与一次前向在 fp32 舍入内相等。seq 在全 K 下的失败主要来自位置外推（候选排到训练没见过的位置）和前缀被上百个候选稀释。位置绑定后，无论 K 多大，最大位置编号都是前缀长度 + 26。
3. 分布内：pointwise −0.5 个点（CI [−1.1, +0.2]，按 1 个点的非劣界，准确率的非劣性没有严格成立；NLL 非劣），set +0.1（两项都非劣）。位置绑定的换序一致率为 1.000，取代 perm-KL；Exp 003 中 perm-KL 只做到 0.980～0.986，且训练成本高约 80%。
4. 候选要不要互看：闭世界下互看在训练分布内有小而显著的收益（set 比 pointwise +0.5 个点、NLL −0.006），主要出现在 snli、boolq、clinc150；在全标签集外推上显著吃亏（−1.9 个点、NLL +0.125），配合分块推理可以补回（0.750 对 0.752）。这与理论一致：闭世界下 IIA 对 Bayes 预测成立，互看不是必需的，也没有集合大小外推的保证；它在固定小集合上的收益属于学习效率，不改变可表达的最优解。
5. 选项经过设计的集合（typed-decisions / JevBench，IIA 可能不成立）这次只有零样本数字，三臂差异在 1.4 个点以内，不能回答那一侧的问题。

## 局限与下一步

- 单 seed、Stage 0 规模；主终点的效应远大于 seed 方差，次要比较（±0.5 个点）需要 3 seeds 复核。
- 下一步：在 typed-decisions 上用 pointwise / set 各训一个 specialist（Exp 014 配方），检验选项经过设计时互看是否变得必要；另可试 set 臂加 K 课程（Exp 006）能否消除外推损失。

## 3 seed 复核（2026-09-24；seed 0 = 上表原始运行，seed 1、2 同配置重训；`runs/exp016_seeds_*_paired.json`）

均值 ± 样本标准差，每格 3 seeds。

| 臂 | 全标签集 一次前向 acc / NLL（n=3,567） | 全标签集 chunk 12 + tournament acc / NLL | 分布内 acc / NLL（test 前 6,000） | 换序一致率 | 去一候选 mean TV |
|---|---|---|---|---|---|
| seq | 0.579 ± 0.018 / 1.852 ± 0.135 | 0.738 ± 0.003 / 0.949 ± 0.022 | 0.857 ± 0.002 / 0.353 | 0.971 | 0.025 |
| pointwise | 0.759 ± 0.006 / 0.835 ± 0.020 | 0.758 ± 0.006 / 0.835 ± 0.020 | 0.856 ± 0.002 / 0.351 | 0.999 | 0.001 |
| set | 0.730 ± 0.002 / 1.031 ± 0.045 | 0.753 ± 0.003 / 0.860 ± 0.006 | 0.857 ± 0.002 / 0.350 | 0.999 | 0.006 |

- 主终点复现：pointwise 一次前向比 seq 高 18.0 个点（seed 0 单次为 19.2；seed 0 配对 CI [17.6, 20.8]，McNemar p < 1e-100），三个 seed 全部在 17～20 之间。seq 的一次前向不但低，而且 seed 方差是别人的 3～9 倍（±1.8），位置外推的失败本身就不稳定。
- pointwise 的分块推理与一次前向在三个 seed 上都相等（0.759 vs 0.758），set 也只差 2.3 个点；seq 靠分块锦标赛能追回到 0.738，仍低 pointwise 2.0 个点、NLL 高 0.11，且方差内不重叠。
- 分布内三臂无差异（0.856～0.857，差距小于 seed 方差），拓扑约束不花准确率。
- 置换等变与 IIA 的探针在三个 seed 上都成立（pointwise 去一候选 TV 0.001，是数值噪声量级）。

## JevBench 公开题上的候选拓扑三臂（Exp 016 checkpoint，Stage 0 规模，seed 0，本机 MPS，原生概率，无温度）

同一 Stage 0 配置下 Exp 001 的 seq 模型此前为 easy 97.9 / standard 61.1 / hard 26.1。三臂只改候选排布。

| 臂 | easy (48) | standard (72) | hard (111) | 全部 (231) |
|---|---|---|---|---|
| seq | 0.958 | 0.667 | 0.279 (31/111) | 0.541 |
| pointwise | 0.917 | 0.528 | 0.342 (38/111) | 0.519 |
| set | 0.917 | 0.569 | 0.351 (39/111) | 0.537 |

hard 层按题型（seq / pointwise / set）：long_policy 3 / 8 / 8 of 19，tradeoff 3 / 5 / 5 of 6，temporal_numeric 3 / 5 / 4 of 15，probability 4 / 5 / 6 of 10，routing_hard 1 / 2 / 3 of 5；multi_hop 4 / 2 / 3 of 18，ambiguous 2 / 0 / 0 of 7；judge_hard 7 / 7 / 7，trap 1 / 1 / 1 不变。配对翻转（hard）：seq 对而 pointwise 错 9 题，pointwise 对而 seq 错 16 题。

结论：位置绑定拓扑在 hard 层高 6～7 个点（27.9 → 34.2 / 35.1），达到发布版（Exp 010，18.6 万条 + GLiClass 初始化 + 1024 token）的水平 34.2；提升集中在 long_policy 和 tradeoff 这类候选是长句、需要逐个对照 state 的题型。easy 层低 2 题、standard 层低 5～6 题，全部合计 seq 仍高 0.4～2.2 个点；111 题的区间 ±9 点，单 seed，只能读作方向。ambiguous（0/7）是 pointwise 的结构性弱项："none of the above / 需要澄清" 这种选项的正确性依赖其他选项，IIA 假设在此不成立。
