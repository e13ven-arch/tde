## 结论

1. 读出位置比读出结构重要：把候选标记从新增 token 换成 MLM 的 [MASK] 并加候选 span 均值，joint 从 58.6% 到 86.2%，学习效率提高数倍（Mac 上 3,200 条样本即达 v1 用 16,000 条的水平）。
2. joint v2 全面优于 biencoder，差距集中在需要候选与 state 交互的任务（snli +7.3、boolq +4.2、go_emotions +7.2 个点）。
3. 意图路由（banking77 / clinc150 / ag_news）在 5% 错误率下可自动处理 89%～95%。
4. 校准是训练出来的：各桶温度 ≈1，全局 ECE 0.011 对噪声下限 0.010。唯一校准差的切片是 score 原语（ECE 0.166 对 0.140），且准确率只有 52%，是 Exp 003 的重点。
5. 留出模板与训练模板持平（88.3% 对 85.8%），无 state 时降到 43%，模型未记模板。
6. 候选换序一致率 98%（joint v2），perm-KL 权重 0.1 偏小。
7. branch v2 落后 joint v2 约 17 个点且训练慢一倍（随机 batch 里 state 无法共享）。Stage 0 结论：以 joint v2 为默认读出；branch 只在「同一 state 多问题」的推理场景有意义，Stage 1 用 group_by_state 重测其训练成本，并考虑用 backbone 末层初始化交叉注意力层。
