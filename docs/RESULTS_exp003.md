## 结论

1. 在 150M 编码器、10 万量级数据上，soft-CE、Brier、CE+Brier 三种 proper scoring rule 的准确率、NLL、ECE、AURC 差异都小于单 seed 的可检出量（n=6,000 时配对 MDE 约 1.5 个点），证实它们共享同一总体最优解；后验温度全在 1.01～1.04，校准来自目标函数本身。
2. 置信头没有改善错误检测（AUROC 0.835 对 0.845），max-prob 已经是同样好的弃答信号。
3. perm-KL 是唯一有可测效应的项，且只作用于候选换序一致率（98.0% 对 92.3%），对准确率和校准无影响；Stage 1 用 0.3 得到 98.6%。
4. 有序打分不是损失函数问题，是读出结构问题（见第二期计划）。
5. 以上均为单 seed；论文版需 3 seeds 复核，但当前差异远小于 seed 间方差的合理范围。
