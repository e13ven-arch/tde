## 结论与后续

1. 定向数据有效但幅度有限：hard 层 +4.5 个点到 Laya 水平；起作用的是 policy 类，multi_hop 类因为两个数据缺陷（截断、位置泄漏）没有起作用。
2. 修正已提交（v0.4：多跳 JSON 压缩到 p90 436 token、HotpotQA 段落乱序），Exp 008 起 state 上限 1024。
3. 任务级 OOD 的真实证据：22 个未见过的法律规则任务 82%，这是可以写进论文的数字。
4. 全标签集变差（banking77 57.1%），混合稀释了 intent 训练；Exp 006 用候选数课程处理。
