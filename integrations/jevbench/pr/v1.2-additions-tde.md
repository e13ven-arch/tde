# TDE general v0.1 (open weights, in-process)

- Adapter: `jevbench/adapters/tde_local.py` (this PR), registered as `tde_local`.
- Weights: Hugging Face `tdelab/tde-general-v0.1` (Apache-2.0), folder loadable with `tde.inference.Decider.from_run`.
- Code: `pip install git+https://github.com/e13ven-arch/tde` (package `tde`; torch, transformers ≥ 4.48).
- Run: `JEVBENCH_WARM_LOAD=1 python -m jevbench.cli run --tasks datasets/public/easy.jsonl,datasets/public/original.jsonl,datasets/public/hard.jsonl --adapter tde_local --endpoint /path/to/tde-general-v0.1 --model tde-general-v0.1 --results results/tde/results.jsonl --raw-dir /tmp/tde-raw --ledger results/tde/ledger.jsonl --cap-usd 1 --reserve-usd 0`
- Probability source: native softmax over the exact label set (noul → {no, yes}; score → level indices as strings). No generation, no renormalisation needed (n_renormalized = 0 on the public items).
- Mapping: choice criteria map → candidates `name: description`; score criteria list → ordered levels with a learned level-index embedding; noul criteria → yes/no candidate descriptions.
- Public-item self-run (2026-09-22, Apple M5 Pro, MPS): 231/231 valid, accuracy 0.563 overall (easy 1.000, standard 0.611, hard 0.342), Brier 0.552, ECE(10 bins) 0.115, ordinal MAE 0.644.
- Cost basis: local weights, no provider tariff (`price = null`). Latency on the public run ≈ 20–40 ms per decision on MPS.
- Contamination statement: training data never included JevBench items or paraphrases of them; 13-gram overlap check between all training states and the public items = 0.
